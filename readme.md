# Conversor de Temperaturas

> **Projeto Acadêmico** — Curso Técnico em Desenvolvimento de Sistemas (SENAI)

Aplicação desenvolvida em Python para realizar conversões entre as escalas termométricas Celsius, Fahrenheit e Kelvin por meio de uma interface interativa em terminal, aplicando conceitos de modularização e estruturas de repetição.

---

## 📌 Sobre o Projeto

O objetivo do projeto é exercitar e demonstrar o aprendizado dos conceitos fundamentais de lógica de programação e Python, incluindo:
* **Funções modulares:** criação de uma função dedicada para cada tipo de conversão.
* **Controle de fluxo:** uso da estrutura `while True` para manter o menu ativo de forma contínua.
* **Tratamento de exceções e validação:** prevenção de falhas ao inserir opções ou valores inválidos.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Interface:** Terminal / CLI

## 📋 Funcionalidades

- [x] 1 - Celsius para Fahrenheit
- [x] 2 - Celsius para Kelvin
- [x] 3 - Fahrenheit para Celsius
- [x] 4 - Fahrenheit para Kelvin
- [x] 5 - Kelvin para Celsius
- [x] 6 - Kelvin para Fahrenheit
- [x] Validação contra entradas não numéricas e opções incorretas do menu

## 🚀 Como Executar

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/daviclementinonascimento123-arch/conversor-temperatura.git

   ```

